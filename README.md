# MastersIndia FE Assignment

This project is a React + TypeScript web application built with Vite for displaying invoice data in a responsive grid-based UI.

## Project Overview

The app renders a list of invoice records using a custom grid component with keyboard-friendly navigation and efficient rendering for large datasets.

## Technologies and Libraries Used

- React 18 - UI library for building the interface
- TypeScript - Strongly typed JavaScript for safer development
- Vite - Fast development build tool and local server
- Tailwind CSS - Utility-first styling framework
- TanStack React Virtual - Efficient rendering for large lists and tables
- clsx - Utility for conditionally joining class names
- ESLint - Code quality and linting support

## Prerequisites

Make sure you have the following installed on your machine:

- Node.js (recommended version 18 or above)
- npm

## Run the Project Locally

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd mastersindia-fe-assignment
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit:
   ```text
   http://localhost:5173
   ```

## Build for Production

To create a production build:

```bash
npm run build
```

## Preview the Production Build

```bash
npm run preview
```
